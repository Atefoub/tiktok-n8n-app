Politique de confidentialité – n8n TikTok local

Dernière mise à jour : 16 septembre 2026

Données traitées

  • Informations de base du compte TikTok du propriétaire (identifiant, nom affiché), obtenues via le scope user.info.basic.
  • Jetons d'accès OAuth permettant d'envoyer des vidéos en brouillon via le scope video.upload.

Utilisation

Ces données servent uniquement à déposer les vidéos du propriétaire en brouillon sur son propre compte. Elles ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires.

Stockage

Les jetons sont stockés chiffrés dans une instance n8n auto-hébergée sur la machine du propriétaire. Aucune donnée n'est stockée par cette page web. La page de retour (callback) affiche seulement le code d'autorisation dans le navigateur, sans l'enregistrer ni le transmettre.

Utilisateurs tiers

Aucune donnée d'autres utilisateurs TikTok n'est collectée.

Durée et suppression

Les jetons sont supprimés dès que l'outil n'est plus utilisé. L'accès peut être révoqué à tout moment depuis les paramètres TikTok (Sécurité → Applications autorisées).
