# Pages publiques de l'app TikTok « n8n TikTok local »

Pages exigées par le formulaire TikTok for Developers : accueil, conditions d'utilisation, politique de confidentialité, et une page de retour OAuth qui affiche le code d'autorisation.

## Publication sur GitHub Pages
1. Crée un dépôt **public** nommé `tiktok-n8n-app`.
2. Envoie ces fichiers à la racine du dépôt.
3. Settings → Pages → Source : *Deploy from a branch* → `main` / `/ (root)` → Save.
4. Attends environ 1 minute, puis ouvre `https://<pseudo>.github.io/tiktok-n8n-app/`.
